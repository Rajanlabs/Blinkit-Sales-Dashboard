# 🛒 Blinkit Grocery Sales Dashboard | Power BI

## 📌 Project Overview

The **Blinkit Grocery Sales Dashboard** is an interactive Power BI project designed to analyze grocery sales performance across different item categories and outlet characteristics.

The dashboard provides a consolidated view of key performance indicators (KPIs), sales trends, and outlet-level performance to support data-driven business analysis.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Understand sales distribution by item fat content.
- Identify high-performing item categories.
- Compare sales across outlet location tiers.
- Evaluate sales by outlet size and outlet type.
- Present key business metrics through interactive visualizations.

## 📈 Dashboard Features

### 1. Sales by Outlet Establishment
Visualizes sales trends based on outlet establishment year.

### 2. Sales by Item Fat Content
Compares sales for Low Fat and Regular item categories.

### 3. Sales by Item Type
Analyzes sales contributions from different grocery product categories.

### 4. Sales by Outlet Location
Compares performance across Tier 1, Tier 2, and Tier 3 locations.

### 5. Sales by Outlet Size
Examines sales distribution across Small, Medium, and High outlet-size categories as represented in the dashboard.

### 6. Sales by Outlet Type
Highlights sales contributions from different outlet types.
